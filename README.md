# Herren 1 · Matchanalyse

Eigenständige Streamlit-App für die Matchanalyse des VBC Frauenfeld Herren 1.

Enthalten sind Live-Erfassung, Video-Nachbearbeitung, Rotationen, Spieleranalyse,
PDF-Export und der Herren-1-Kader. Das Projekt ist unabhängig von der bisherigen
Volleyball-App.

## Lokal starten

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

Die laufende SQLite-Datenbank wird absichtlich nicht im Repository gespeichert.
